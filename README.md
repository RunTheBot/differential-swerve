# Differential Swerve



Swerve Module - But it's differential. 

## What is Swerve Drive?
Swerve drive is a drive train allowing the wheels to be vectored in any direction. The advantage of this is that all the force the motors output goes towards the direction you want to go.

## What is Differential Swerve
A differential swerve allowed for both the drive and steer motors to control both axis. This way, when not turning the wheels both motors are able to contribute going very very fast. Vrooom!
